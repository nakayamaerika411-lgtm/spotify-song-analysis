# 🎧 Spotifyヒットソング分析プロジェクト：Python/MySQLを用いたデータ分析とAI協調

本プロジェクトは、Pythonを用いた一連のデータ処理（収集、クレンジング、DB格納、分析）を独力で行い、その過程で生成AI（Gemini）を教師・デバッガーとして活用することで、**現代のデータ分析に必要なスキルセットと高い問題解決能力**を証明するために実施されました。

## 🚀 プロジェクトの目的と使用技術

| 項目 | 詳細 | 達成目標 |
| :--- | :--- | :--- |
| **最終目標** | 楽曲データから人気度（Popularity）に影響を与える**音楽的要素**を特定し、その結果を**論理的な結論**として導出する。 |
| **使用技術** | Python (Pandas/Matplotlib/Seaborn), MySQL, **生成AI (Gemini)**, Git/GitHub |
| **アピール** | AIとの協調による**高速な実行能力**と、元翻訳者としての**論理的思考力**。 |

---

## 🛠️ プロジェクトの実行プロセス

| スクリプト | 概要 | 役割 |
| :--- | :--- | :--- |
| `spotify_collector.py` | Spotify APIからヒットソングデータ（楽曲情報、特徴量）を収集。 | データ収集 (Extraction) |
| `genius_collector.py` | Genius APIから楽曲の歌詞URLを追加で収集し、データを統合。 | データ統合 (Transformation) |
| `mysql_uploader.py` | 収集・統合したデータをMySQLデータベースに格納。複雑な**データ型変換ロジック**を実装。 | データベース管理 (Loading) |
| `data_analyzer.py` | MySQLからデータを取得し、Pandasで分析（相関分析）、Matplotlib/Seabornで可視化。 | データ分析と可視化 (Analysis) |

---

## 📊 分析の主要な発見と結論 (Key Findings)

約630曲のヒットソング（Popularity >= 70）を分析した結果、人気度と楽曲の特徴量には以下の相関関係が見られました。

| 特徴量 | 相関係数 ($R$) | 結論と市場の示唆 |
| :--- | :--- | :--- |
| **Danceability** (踊りやすさ) | **+0.187** (最も強い正の相関) | ヒット曲には**アップビートでノリの良いリズム**が最も強く求められる。 |
| **Energy** (エネルギー) | **+0.165** (強い正の相関) | 高揚感や勢いのある楽曲が人気に貢献する。 |
| **Acousticness** (アコースティック度) | **-0.203** (最も強い負の相関) | ヒットチャートでは**生音の要素が忌避**される傾向があり、**クリーンでデジタル加工されたサウンド**が主流である。 |
| **Instrumentalness** | 0.5を超える曲の割合は **0.00%** | ヒット曲において**ボーカル（歌詞）は必須要素**である。 |

### 考察

ヒット市場は**「ノリの良さ」**と**「デジタル的なクリーンさ」**を強く求めています。楽曲制作において、高エネルギーかつダンスに適した要素に重点を置き、アコースティックな響きを抑えることが、人気獲得の鍵になると結論づけられます。
